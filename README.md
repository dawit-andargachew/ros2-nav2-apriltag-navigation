# GROUP 6 ASSIGNMENT 1

Code repository of the first assignment for the Intelligent Robotics course.
Developed by Dawit Andargachew Asmare, Tharen Emmanuel Candi and Giuseppe Castellana (Group 6).

# HOW TO RUN

After having cloned the repo, run these commands in your terminal from the workspace where the project has been cloned:
colcon build --packages-select group_6_assignment_1
source install/setup.bash
ros2 launch group_6_assignment_1 group_6_assignment_1.launch.py
